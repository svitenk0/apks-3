# АПКС — Лабораторна робота №3: I2C Master на Verilog

**Варіант 20:** протокол **I2C**, мова **Verilog**.
Виконав: Світенко Павло Ігорович, група КІ-408.

Контролер I2C Master (Standard-mode 100 кГц / Fast-mode 400 кГц) з окремими модулями
передавача (`i2c_tx`) і приймача (`i2c_rx`), генератором фаз SCL із підтримкою
clock stretching і самоперевірним тестбенчем.

## Структура

```
rtl/
  i2c_master_top.v   верхній рівень: виводи SCL/SDA з відкритим стоком (inout)
  i2c_master.v       ядро: синхронізатори, генератор фаз SCL, FSM транзакції
  i2c_tx.v           передавач байта (адреса / дані) + прийом ACK
  i2c_rx.v           приймач байта + видача ACK/NACK
tb/
  tb_i2c_master.v    тестбенч: clk/rst, тести T1–T7, підсумок PASS/FAIL
  i2c_slave_model.v  модель веденого 0x50 (пам'ять 256 Б, clock stretching)
  i2c_monitor.v      незалежний декодер шини + вимірювання t_LOW/t_HIGH/f_SCL
sim/
  run_sim.sh         симуляція Icarus Verilog для 100 кГц і 400 кГц
  plot_waves.py      осцилограми з VCD -> docs/img/wave_*.png
docs/
  draw_fsm.py        діаграми станів -> docs/img/fsm_*.png
  img/               діаграми FSM і осцилограми
```

## Інтерфейс `i2c_master_top`

| Порт | Напр. | Опис |
|------|-------|------|
| `clk`, `rst_n` | in | тактова частота (`CLK_FREQ`, типово 50 МГц), синхронне скидання (0) |
| `cmd_start` | in | імпульс запуску транзакції |
| `cmd_addr[6:0]`, `cmd_rw`, `cmd_len[7:0]` | in | адреса веденого, 0 = запис / 1 = читання, кількість байтів (0 = probe) |
| `tx_data[7:0]` / `tx_req` | in / out | байт запису / імпульс «байт узято, дай наступний» |
| `rx_data[7:0]` / `rx_valid` | out | прийнятий байт / імпульс дійсності |
| `busy`, `done`, `ack_err` | out | шина зайнята, транзакцію завершено, ведений відповів NACK |
| `scl`, `sda` | inout | лінії I2C (відкритий стік, зовнішні pull-up) |

Параметри: `CLK_FREQ` (Гц), `SCL_FREQ` (Гц). Такт SCL = 4 фази: 2 фази низького рівня
(≈60 %) і 2 високого (≈40 %), що виконує вимоги UM10204 до t_LOW / t_HIGH.

## Запуск симуляції

Потрібен [Icarus Verilog](https://bleyer.org/icarus/) (Windows: `winget install Icarus.Verilog`).

```bash
bash sim/run_sim.sh            # 100 кГц і 400 кГц; лог і VCD у build/sim/
python sim/plot_waves.py       # PNG-осцилограми в docs/img/ (потрібен matplotlib)
gtkwave build/sim/tb_100000.vcd   # перегляд у GTKWave (необов'язково)
```

Очікуваний результат: `==== TEST PASSED (24 checks) ====` для обох частот і `SIM: SUCCESS`.

## Тести

| № | Сценарій | Що перевіряється |
|---|----------|------------------|
| T1 | запис 5 байтів у 0x50 | потік бітів на шині (монітор), вміст пам'яті веденого |
| T2 | зворотне читання 4 байтів | `rx_data`, ACK×3 + NACK на останньому байті |
| T3 | читання даних веденого | прийом даних, сформованих іншим пристроєм |
| T4 | адреса 0x23 (немає пристрою) | NACK → `ack_err`, STOP, шина вільна |
| T5 | clock stretching 10 мкс | генератор фаз чекає, дані коректні |
| T6 | address probe (`len = 0`) | ACK присутнього пристрою |
| T7 | часові параметри | f_SCL ≤ номіналу, t_LOW / t_HIGH ≥ мінімуму UM10204 |
